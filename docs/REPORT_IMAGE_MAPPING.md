## Panduan Screenshot Manual

### 01 — Development Server
| Atribut | Detail |
| --- | --- |
| **Cara ambil** | Buka terminal PowerShell di direktori `D:\pasar_fix`. Jalankan `bun run dev`. Tunggu hingga muncul "Server running on http://localhost:3000". |
| **Area capture** | Seluruh terminal window — tunjukkan command `bun run dev` + output server siap. |
| **Simpan di** | `screenshots/bab3/setup/screenshot_01.png` |

### 02 — Detail Commit Stall
| Atribut | Detail |
| --- | --- |
| **Cara ambil** | Buka terminal PowerShell di direktori `D:\pasar_fix`. Jalankan `git show 7a38bb7 --stat`. |
| **Area capture** | 5–10 baris pertama: commit hash, author, date, message, daftar file yang diubah. |
| **Simpan di** | `screenshots/bab3/kontribusi/screenshot_02.png` |

### 03 — File Excel Data Survei
| Atribut | Detail |
| --- | --- |
| **Cara ambil** | Buka File Explorer ke `D:\pasar_fix\data\`. Pilih file `SURVEY PASAR KIOS (Jawaban).xlsx`. Buka Properties (Alt+Enter) untuk lihat size dan type. |
| **Area capture** | File terpilih di Explorer + panel Properties (nama, ukuran, tipe). **Sensor nama responden** jika ada di preview. |
| **Simpan di** | `screenshots/bab3/survei/screenshot_03.png` |

### 07 — Session Cookie DevTools
| Atribut | Detail |
| --- | --- |
| **Cara ambil** | Buka browser ke http://localhost:3000/admin (login dulu). Buka DevTools (F12 → Application → Cookies → `localhost:3000`). Cari cookie session (biasanya `better-auth.session_token`). |
| **Area capture** | Tabel cookie — tunjukkan Name, Domain, Path. **Blur/sensor Value cookie** sebelum simpan. |
| **Simpan di** | `screenshots/bab3/auth/screenshot_07.png` |

### 26 — Detail Stall Publik (MANUAL*)
| Atribut | Detail |
| --- | --- |
| **Cara ambil** | Buka http://localhost:3000/admin/stall. Copy UUID dari baris pertama tabel (kolom paling kiri). Buka http://localhost:3000/stall/{UUID}. |
| **Area capture** | Halaman detail kios publik: nama kios, alamat, kontak, daftar brand yang tersedia. |
| **Simpan di** | `screenshots/bab3/stall/screenshot_26.png` |

### 32 — Daftar Tabel Drizzle Studio
| Atribut | Detail |
| --- | --- |
| **Cara ambil** | Buka terminal, jalankan `bun run db:studio`. Buka browser ke URL yang muncul (biasanya http://localhost:4983). Capture panel kiri Drizzle Studio yang menampilkan seluruh tabel. |
| **Area capture** | Panel kiri Drizzle Studio — daftar semua tabel (22 tabel). Pastikan semua tabel terlihat. |
| **Simpan di** | `screenshots/bab3/database/screenshot_32.png` |

### 33 — ERD 22 Tabel
